# SpaceSurvival ItemsAdder source pack

This directory is the Git-tracked source of truth for the project's optional ItemsAdder presentation layer.

Runtime destination:

```text
dev-server/server/plugins/ItemsAdder/contents/spacesurvival/
```

The runtime copy is generated by `dev-server/quick-deploy.bat`. Edit this tracked source instead of the runtime folder.

## Current IDs

- `spacesurvival:repair_parts`

- `spacesurvival:research_scanner`
- `spacesurvival:radio`
- `spacesurvival:cargo_scanner`

World presentation:

- `spacesurvival:hull_breach`

The included PNG files are deliberately simple placeholder pixel art. They are safe to replace later as long as the file names and item IDs stay unchanged.

Gameplay must continue to work without ItemsAdder; vanilla fallback items remain authoritative for compatibility.

## Local test

After a deploy and server start:

```text
/iazip
/iaget spacesurvival:repair_parts
```

If the custom texture is visible, the SpaceSurvival -> ItemsAdder integration is active.
