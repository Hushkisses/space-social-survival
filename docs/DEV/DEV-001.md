# DEV-001 Project Bootstrap

## Goal

Create the initial multi-module Paper plugin project so the repository can build, test, and load a minimal plugin on Paper.

## Scope

- Gradle 9.7.1 Wrapper
- Java 25 toolchain
- Kotlin DSL build scripts
- `core` module
- `paper-plugin` module
- JUnit 5 baseline
- Paper plugin metadata
- minimal plugin bootstrap
- `/space status` admin command
- GitHub Actions build workflow
- local dev-server helper scripts/documentation

## Non-goals

- GameSession implementation
- roles
- objectives
- map generation
- ItemsAdder integration
- voice integration
- MythicMobs / ModelEngine integration

- README.md

```text
dev/DEV-001-bootstrap
```

## Tests

- `./gradlew test`
- `./gradlew build`
- minimal core unit-test baseline

## Manual validation

On the Windows Paper development server:

1. stop server
2. pull DEV branch/build output as appropriate
3. run quick deploy
4. start Paper
5. verify plugin loads
6. run `/space status`
7. verify Korean player-facing output

## Completion criteria

- build succeeds
- tests succeed
- plugin JAR produced
- Paper loads plugin without startup errors
- `/space status` works
- PROJECT-STATE updated
- merged to main after validation
