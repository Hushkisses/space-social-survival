# DEV-002 GameSession Core

## Goal

Implement the pure-Java match session aggregate and explicit lifecycle transitions that will become the source of truth for one game round.

## Scope

- GameSession
- GameSessionId
- GamePhase
- explicit legal lifecycle transitions
- timestamps for session creation / phase change
- terminal FINISHED state
- transition validation
- unit tests
- Paper status command reflects current DEV

## Non-goals

- PlayerState
- lobby player joins
- scenario selection
- ship state
- timer/crisis progression
- persistence
- automatic Paper scheduler transitions

## Lifecycle

```text
WAITING
  -> PREPARING
  -> BRIEFING
  -> ACTIVE
  -> RETURN_PHASE
  -> FINISHED
```

Early termination to `FINISHED` is allowed from PREPARING, BRIEFING, ACTIVE, and RETURN_PHASE so an administrator or future failure condition can safely terminate a session.

`WAITING -> FINISHED` is intentionally not allowed; a never-started session should be discarded rather than recorded as a played match.

## Tests

- initial phase is WAITING
- valid normal lifecycle
- early finish from started phases
- illegal phase skipping rejected
- FINISHED is terminal
- phase-change timestamp updates
- session ID is stable
