# DEV-016 Facility Framework

## Goal

Create a shared facility model for the six initial ship facilities and their simple player-facing states.

## Facility states

- NORMAL
- DAMAGED
- OFFLINE
- QUARANTINED

These directly match the game design's:
정상 / 손상 / 정지 / 격리.

## Initial facilities

- BRIDGE
- ENGINEERING
- MEDICAL
- RESEARCH
- CARGO
- HABITATION

## Scope

- FacilityId
- FacilityType
- FacilityStatus
- FacilityDefinition
- FacilityState
- FacilityRegistry
- DefaultFacilityCatalog
- Paper debug commands
- JUnit coverage

## Design rules

- facility identity/type is static definition data
- current status is mutable runtime state
- player-facing state remains intentionally simple
- detailed internal values belong to later facility-specific systems
- facility-specific actions are not implemented in DEV-016

## Commands

```text
/space facility list
/space facility status <id>
/space facility set <id> <normal|damaged|offline|quarantined>
/space facility reset
```

## Non-goals

- Engineering mechanics
- Medical mechanics
- facility-local numeric sub-states
- map placement
- access control
- event integration

## Completion criteria

- six default facilities registered
- status transitions work
- invalid facility IDs/statuses rejected
- snapshots are immutable
- commands work in Paper
- tests/build/Paper validation pass
