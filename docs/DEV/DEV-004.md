# DEV-004 Configuration System

## Goal

Externalize initial server and balance values into validated configuration while keeping core rules independent from Bukkit/Paper configuration classes.

## Scope

- core configuration records
- validation rules
- default config.yml
- default balance.yml
- Paper YAML loader
- fail-fast startup on invalid config
- status command reports loaded player limits
- JUnit coverage

## Initial values

```text
min-players: 6
max-players: 10
target-match-minutes: 45
return-hold-seconds: 240
```

These are configuration defaults, not immutable balance constants.

## Non-goals

- roles.yml
- objectives.yml
- scenarios.yml
- events.yml
- resources.yml
- hot reload
- admin configuration commands

## Completion criteria

- config records validate correctly
- plugin saves default files
- plugin loads validated configuration on startup
- invalid values stop plugin enable with clear console error
- tests/build/Paper smoke test pass
