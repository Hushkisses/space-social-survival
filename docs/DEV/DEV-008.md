# DEV-008 Constrained Random Map Generator

## Goal

Generate a connected logical ship layout from registered tile definitions while enforcing structural constraints before any physical placement occurs.

## Scope

- MapGenerationConstraints
- GeneratedMap
- GeneratedConnection
- ConstrainedRandomMapGenerator
- deterministic seeded generation support
- validation/retry loop
- core reachability
- dead-end limit
- core-to-core graph distance limit
- connection-point capacity enforcement
- JUnit coverage

## Design

The generator works only with logical tile metadata. It does not know Minecraft coordinates, chunks, blocks, or worlds.

Physical placement is intentionally deferred. The current project decision is that actual ship modules will later be placed in a superflat world for easier construction.

## Constraints

The generator accepts constraints as input rather than treating balance values as permanent constants.

Typical initial test values:

```text
tile count: 10..14
max dead ends: configurable
max core distance: configurable
attempt limit: configurable
```

All CORE tiles registered in the candidate pool are mandatory.

## Algorithm

1. include every CORE tile
2. randomly select additional tiles until target size
3. construct a connected graph using unused connection points
4. add extra connections where possible
5. validate:
   - all selected tiles reachable
   - no connection point reused
   - dead ends within limit
   - every pair of CORE tiles within configured graph distance
6. retry with a new randomized layout when validation fails

## Non-goals

- Minecraft block placement
- superflat world generation
- NBT loading
- corridor geometry
- teleport target registration
- map debug commands

## Completion criteria

- deterministic seeded tests pass
- generated layouts are connected
- all CORE tiles are always present
- point capacity is never exceeded
- invalid impossible pools fail clearly
- full build passes
- Paper smoke test remains healthy
