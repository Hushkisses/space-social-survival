# DEV-009 Map Debug Tools

## Goal

Expose developer-facing commands that exercise and inspect the logical map generator before physical ship modules are placed in the flat construction world.

## Scope

- debug tile pool matching the planned initial 20-tile composition
- /space map generate [seed]
- generated tile list output
- generated connection output
- graph summary output
- deterministic seed support
- Korean player/admin-facing output

## Debug tile pool

The temporary debug pool mirrors the design baseline:

- CORE 6
- CORRIDOR 5
- JUNCTION 3
- AIRLOCK 2
- AUXILIARY 4

These are synthetic logical debug definitions, not final physical map content.

## Generation defaults

- tile count: 10..14
- max dead ends: 6
- max CORE distance: 6
- max attempts: 500

These are debug defaults only and are not final balance values.

## Command

```text
/space map generate
/space map generate <seed>
```

Output includes:

- seed
- selected tile count
- connection count
- dead-end count
- selected tile IDs/categories
- logical connections

## Non-goals

- block placement
- Structure Block/NBT loading
- actual flat-world coordinates
- teleport target registration
- production map content configuration

## Completion criteria

- command generates a logical map without touching the world
- same seed produces the same topology
- malformed seed returns a Korean usage/error message
- full build and Paper smoke test pass
