# DEV-007 Connection & TP

## Goal

Add runtime connection access states and a Paper teleport adapter that can move players between logical connection endpoints once physical destinations are registered.

## Scope

- ConnectionState
- ConnectionAccessContext
- ConnectionAccessDecision
- connection access policy
- TileConnectionPointRef
- ConnectionRoute
- Paper teleport target registry
- asynchronous Paper teleport service
- unit tests
- status command update

## Supported states

```text
OPEN
LOCKED
POWER_REQUIRED
KEYCARD_REQUIRED
DISABLED
```

## Access rules

- OPEN: allowed
- LOCKED: denied
- POWER_REQUIRED: allowed only when power is available
- KEYCARD_REQUIRED: allowed only when keycard access is available
- DISABLED: denied

## TP flow

```text
source connection point
→ access decision
→ target logical connection point
→ registered Paper Location
→ teleportAsync
```

Physical destinations remain outside core. The Paper adapter owns Bukkit/Paper Location values.

## Non-goals

- automatic door listeners
- proximity triggers
- YAML coordinate loading
- safe-position search
- random map generation
- power system implementation
- keycard item implementation

## Completion criteria

- all access states are tested
- routes reject self-links
- Paper teleport adapter compiles against Paper 26.2
- unknown physical targets fail without teleporting
- full build passes
- Paper smoke test remains healthy
