# DEV-013 Briefing & Initial Goal UI

## Goal

Replace the DEV-012 command-only role choice path with player-facing Paper UI and present the opening accident briefing, initial problems, and first common objective.

## Scope

- opening briefing inventory UI
- role candidate inventory GUI
- click-to-select role using existing RoleSelectionService
- automatic GUI open after admin prepares role candidates
- developer reopen commands
- initial common-goal and initial-problem presentation
- Korean player-facing text
- inventory click protection
- Paper smoke validation

## Opening flow represented in DEV-013

1. public accident briefing
2. show three role candidates
3. choose one role
4. show initial problems
5. show common objective

Private objective assignment and starter equipment are deliberately not fabricated here because their authoritative systems are planned later:

- DEV-020+ resources/items
- DEV-024+ objective engine

## Initial UI content

The UI uses the game-design baseline as a presentation prototype:

- accident: damaged ship / multiple systems unstable
- initial problem examples:
  - power output low
  - medical auxiliary power offline
  - long-range communications offline
- common objective:
  - Stage 1 — restore survival infrastructure

These are briefing presentation placeholders until ShipState, Facility, Event, and Objective systems supply live data.

## Commands

```text
/space briefing
/space role gui
/space role prepare [seed]
```

`/space role prepare [seed]` prepares candidates and opens the briefing/role flow for online lobby members.

## Non-goals

- private objective engine
- starter item distribution
- live ship-state values
- live facility damage generation
- role-specific gameplay effects

## Completion criteria

- briefing GUI opens
- role GUI displays exactly the player's three candidates
- clicking a candidate selects via RoleSelectionService
- successful selection closes GUI and confirms in Korean
- invalid/full/already-selected choices cannot bypass core rules
- tests/build/Paper validation pass
