# DEV-010 Lobby & Start Flow

## Goal

Create the first real multiplayer entry flow: players join a lobby, the configured player limits are enforced, connection state is tracked, and an administrator can start a match into PREPARING.

## Scope

- LobbyService
- join / leave
- min/max player enforcement
- reconnect/disconnect state tracking
- lobby snapshot/status
- match start creates GameSession
- match start transitions WAITING -> PREPARING
- /space lobby join
- /space lobby leave
- /space lobby status
- /space lobby start
- Paper join/quit connection listener
- Korean player-facing messages
- JUnit coverage

## Rules

- lobby capacity comes from GameConfig
- duplicate join is idempotent
- lobby membership cannot change after match start
- start requires at least min-players
- start may not happen twice
- only users with spacesurvival.admin may start
- ordinary players may use lobby join/leave/status

## Non-goals

- role assignment
- role candidate UI
- public briefing
- starter items
- map placement
- match timer
- persistence across server restart

## Completion criteria

- 6..10 configured lobby capacity enforced
- disconnect does not remove match/lobby state
- reconnect restores connected state
- start creates exactly one GameSession in PREPARING
- commands work on Paper
- tests/build/Paper validation pass
